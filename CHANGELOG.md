# Escape Export & Import Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/) and this project adheres
to [Semantic Versioning](http://semver.org/).

## 2.0.1 - 2023-08-22

### Fixed
- Fixed a Craft 4 compatibility issue w/ permissions

### Added

- Added Craft 4 compatibility

## 2.0.0 - 2023-07-29

### Added

- Added Craft 4 compatibility

## 1.3.0 - 2021-12-15

### Added

- Adds "Target Section" setting, to import entries to a different section than the one they were exported from

## 1.2.1 - 2021-10-21

### Fixed

- Fixes an issue where elements were not exportable on Craft 3.7.x

## 1.2.0 - 2020-10-16

### Added

- Added support for categories

## 1.1.5 - 2020-09-25

### Improved

- Import sequence for assets now fall back to regular download if a DAM image couldn't be downloaded

## 1.1.4 - 2020-09-24

### Fixed

- Fixes an issue where Export/Import would break nested entry sources

## 1.1.3 - 2020-09-22

### Fixed

- Fixes an issue where DAM imports would fail in console requests, because the user wasn't authenticated

## 1.1.2 - 2020-09-22

### Fixed

- Fixes an issue where the user/author was not identified in console requests

## 1.1.1 - 2020-09-22

### Fixed

- Fixed an issue where Assets were not exportable

## 1.1.0 - 2020-09-22

### Added

- Added user permissions

## 1.0.0 - 2020-09-22

### Added

- Initial release
